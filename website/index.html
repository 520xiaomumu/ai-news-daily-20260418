编辑精选

1) 谷歌推出 Android 开发工具集，优化 Agent 工作流

Google 这次不是单独发模型，而是直接把 Android Agent 开发工具链产品化。对移动端开发者来说，真正的变化是 AI 编码开始从“会写代码”走向“会搭环境、会查文档、会跑流程”。

2) browser-use 推出 Browser Harness 开源工具

Browser Harness 很值得看，它代表一种更激进的浏览器 Agent 路线，不只是点页面，而是能边运行边补代码。对自动化测试、网页采集和复杂工作流来说，这类自愈式浏览器框架会越来越重要。

3) 传闻称 DeepSeek 本周发布 V4 模型，总参数或达 1600B

如果 DeepSeek V4 本周真的落地，而且规模上到 1.6T，那国产开源大模型竞争会再次升温。不过目前仍是传闻，判断价值主要看正式发布时的实际成本、速度和基准表现。

4) Vercel 官方证实内部系统遭未授权访问，仅小部分客户受影响

Vercel 安全事件虽然官方称影响范围有限，但对开发团队是个很直接的提醒，所有托管平台都不该被默认视作绝对安全，环境变量、密钥轮换和权限隔离仍然是基本功。
